# 📦 КаргоМост — Оптимизированный лендинг для Яндекс.Директа с SOCKS5H и Метрикой

Комплексное решение для рекламы карго и доставки грузов из Китая в Россию:
1. **Максимальная оптимизация под Яндекс.Директ** (динамический мультилендинг под поисковые запросы, захват `yclid`, `_ym_uid`).
2. **Иерархия целей Яндекс.Метрики** (макро-цели для назначения конверсионных ставок и микро-цели для обучения автостратегий).
3. **Бэкенд с поддержкой SOCKS5H** (Python и PHP) для бесперебойной отправки заявок в Telegram через прокси с удаленным DNS-резолвом.

---

## 🎯 1. Оптимизация под Яндекс.Директ

В нише карго цена клика на Поиске высокая. Чтобы снизить стоимость клика (CPC) и повысить коэффициент качества (Quality Score) объявлений, в лендинг встроен **динамический мультилендинг**:

### Как это работает:
Сайт автоматически считывает параметры URL (`utm_term`, `utm_content`, `utm_campaign`, `keyword`, `text`) и **на лету подменяет первый экран и настройки калькулятора**:

| Запрос / Метка в Директе | Что видит посетитель на первом экране | Что переключается в калькуляторе |
| :--- | :--- | :--- |
| `wildberries`, `вайлдберриз`, `ozon`, `озон`, `маркетплейс`, `селлер` | **H1:** Карго из Китая для Wildberries и Ozon с гарантией сроков<br>**Бейдж:** 🛍️ Спецусловия и маркировка для селлеров WB и Ozon | Категория автоматически переключается на «Одежда, обувь, текстиль» |
| `станок`, `оборудование`, `линия`, `запчасти` | **H1:** Доставка оборудования и станков из Китая под ключ с договором<br>**Бейдж:** ⚙️ Промышленное оборудование и запчасти | Категория переключается на «Автозапчасти, оборудование» |
| `авиа`, `срочно`, `быстро`, `экспресс` | **H1:** Срочная авиадоставка из Китая от 7 дней с фиксированной ценой<br>**Бейдж:** ✈️ Срочная авиадоставка коммерческих партий от 10 кг | Способ доставки автоматически переключается на вкладку «Авиа» |
| `белая`, `официально`, `гтд`, `ндс`, `документы` | **H1:** Белая доставка грузов из Китая с НДС и ГТД на ваше юрлицо<br>**Бейдж:** 📑 100% официальный ввоз, ГТД и закрывающие документы | Акцент на договор и безналичный расчет |
| `санкт-петербург`, `спб`, `екатеринбург`, `казань`, `краснодар` | **H1:** Карго из Китая в {Город} с договором и страховкой | Город автоматически подставляется в заголовок |

> **Как протестировать:** просто откройте сайт с параметром:  
> `?utm_term=карго+из+китая+для+wildberries` или `?utm_term=доставка+станков+из+китая+авиа` — первый экран мгновенно адаптируется!

### Сквозная аналитика:
Сайт автоматически перехватывает **`yclid`** (Yandex Click ID) и **`_ym_uid`** (ClientID Метрики). При отправке заявки эти идентификаторы передаются в Telegram и сохраняются в `leads.csv` — вы сможете делать оффлайн-конверсии в Директ и видеть, с какого именно объявления пришла оплаченная доставка.

## 📊 2. Цели Яндекс.Метрики

Все события уже прописаны в коде `script.js` и дублируются в `window.dataLayer`.

### Как настроить в Яндекс.Метрике:
Зайдите в Метрику -> **Настройка** -> **Цели** -> **Добавить цель** -> тип **«JavaScript-событие»** и введите идентификаторы из таблицы:

### 🏆 МАКРО-ЦЕЛИ (для автостратегий Директа «Оптимизация конверсий»):
* **`lead_form`** — успешная отправка основной квиз-формы (ГЛАВНАЯ ЦЕЛЬ для оплаты за конверсию!).
* **`lead_exit`** — отправка формы из exit-intent окна (заказ чек-листа).
* **`click_telegram`** — клик по кнопке Telegram (для горячих клиентов, которые пишут напрямую).
* **`click_phone`** — клик/тап по номеру телефона.

### 📈 МИКРО-ЦЕЛИ (для обучения кампаний на этапе разгона):
* **`calc_interact`** — клиент изменил вес, объем или категорию в калькуляторе.
* **`calc_method_change`** — переключил тариф (Авто / ЖД / Авиа / Море).
* **`calc_cta_click`** — нажал «Зафиксировать цену в договоре».
* **`quiz_start`** — ответил на Шаг 1 в квизе.
* **`quiz_step_2`** — перешел на Шаг 2.
* **`quiz_step_3`** — перешел на Шаг 3.
* **`quiz_contact_focus`** — начал вводить номер телефона/Telegram.
* **`scroll_50`**, **`scroll_90`** — доскроллил до 50% и 90% страницы.

> **Рекомендация по стратегии Директа:** первые 1–2 недели запускайте кампанию с оптимизацией по микро-цели **`quiz_start`** или **`calc_interact`** (чтобы алгоритм быстро набрал 20+ конверсий), а затем переключайте на оплату за макро-цель **`lead_form`**.

## 🛡️ 3. Отправка заявок через SOCKS5H прокси

Telegram Bot API (`api.telegram.org`) на большинстве российских серверов и хостингов требует защищенного проксирования. Протокол **`socks5h://`** принципиален: он переносит разрешение DNS на сторону прокси (Remote DNS Resolution), обходя блокировки и DPI.

В комплекте идут два готовых решения:

### Вариант А: Запуск через Python (`server.py`)
Идеально для VPS, Docker, локального запуска или собственного сервера:
1. Откройте **`server_config.py`**:
   ```python
   TELEGRAM_BOT_TOKEN = "7123456789:AAH..."  # Токен от @BotFather
   TELEGRAM_CHAT_ID = "-100123456789"         # ID чата или канала
   SOCKS5_PROXY = "socks5h://login:pass@ip:port" # ваш socks5h прокси (или "socks5h://ip:port")
   PORT = 8085
   HOST = "127.0.0.1"                         # публикуйте наружу через reverse proxy
   ```
2. Запустите сервер:
   ```bash
   pip install -r requirements.txt
   python server.py
   ```
   Сервер раздает только публичные файлы, принимает `POST /api/lead`, отправляет заявку в Telegram через SOCKS5H и сохраняет копию в `leads.csv` и `leads.json`. Конфиги и файлы лидов из HTTP недоступны.

### Вариант Б: Запуск на обычном PHP-хостинге (`lead.php`)
Для Beget, Timeweb, cPanel и любого веб-сервера с Apache/Nginx:
1. Откройте **`lead.php`** и укажите:
   ```php
   $botToken    = '7123456789:AAH...';
   $chatId      = '-100123456789';
   $socks5Proxy = 'login:pass@ip:port'; // socks5h прокси
   ```
2. В файле **`config.js`** переключите:
   ```javascript
   formEndpoint: 'lead.php',
   ```
   Скрипт использует `CURLPROXY_SOCKS5_HOSTNAME` (тот самый socks5h) и пишет резервные копии в `leads.csv`. Для Apache в комплекте есть `.htaccess`, запрещающий доступ к файлам данных и служебным файлам.
